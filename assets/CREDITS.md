## Checklist before adding anything

- [ ] Commercial use permitted
- [ ] Modification permitted (you will recolor and edit)
- [ ] Resolution and painting style match what's already in the project
- [ ] Attribution text copied here verbatim if required
- [ ] Source files (layered PSD/Krita, not just flattened PNGs) archived outside the repo

## For commissioned work specifically

- [ ] Contract explicitly assigns **full commercial rights**, not a limited license
- [ ] Deliverables include layered source files and sprite sheets, not just exports
- [ ] Animation timings agreed against the locked movement values from
      `scenes/player/player.gd` — supply `jump_time_to_peak`, `jump_time_to_fall`,
      and `run_speed` as part of the brief
- [ ] Canvas size / character height in pixels specified up front (player ≈ 170px tall)
